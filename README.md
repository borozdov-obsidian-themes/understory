# Borozdov Understory

A theme from the Borozdov collection. Two faces — light **Mossbed**, bone-white beds under
glass, and dark **Nightbloom**, the same greenhouse after the lights go out. Bold compressed
headlines, pill shapes throughout, and one electric-lime green for every action.

![Borozdov Understory in light mode](https://raw.githubusercontent.com/borozdov-obsidian-themes/understory/main/screenshots/light.png)

![Borozdov Understory in dark mode](https://raw.githubusercontent.com/borozdov-obsidian-themes/understory/main/screenshots/dark.png)

## Principles

- **One lime green.** The main button, a checked task, a toggle, links and the open file all
  run through the same electric-lime; a quieter Deep Verdant carries hover and active states.
- **Bold compressed headlines.** Every heading at weight 700 in the platform's sans, tight
  line-height and a touch of negative tracking as size grows — the greenhouse-beam stack.
- **Bone-white beds, forest-dark canvas.** By day the page is a warm off-white bed behind
  bright white cards; by night it's a deep forest surface with a hairline frame on every
  panel.
- **Pills everywhere.** Buttons, tags, the note callout and the open file are all fully
  rounded; cards take a generous 16–24px corner.

## Features

- Light and dark modes, following Settings → Appearance → Base color scheme
- The highlighter as a lime word on an opaque wash, readable on both faces
- Callouts as cards with the title in the type's colour; the plain note on a lime-wash chip
- The open file as an inverted lime pill
- Quiet editing: no focus ring around the note, its title or form fields while you type;
  property names read as labels, not boxed fields
- Text colours meet WCAG contrast on both faces
- The phone layout keeps the same colours and shapes
- No embedded fonts, so the theme stays around 12 KB
- No `!important`: every rule can be overridden with a CSS snippet

## Installation

**From the community directory:** Settings → Appearance → Themes → Manage, search for
**Borozdov Understory**, then **Install and use**.

**By hand:** download `manifest.json` and `theme.css` from the [latest
release](https://github.com/borozdov-obsidian-themes/understory/releases/latest) into
`<vault>/.obsidian/themes/Borozdov Understory/`, then choose Borozdov Understory under
Settings → Appearance → Themes.
